# PTime Core Note — Before Sleep / Tomorrow Queue

**Before Sleep → Tomorrow Queue → Next-Day Execution → Close**

PTime should protect the boundary between planning and execution.

### Night
- review open loops
- select 3–5 highest-value items
- define next action
- define best time
- define close condition
- stop opening new branches
- sleep

### Day
- execute the queue
- reach out
- deep talk
- follow up
- complete DD
- submit applications
- close next steps

### PTime Outputs
- Reach Out Now
- Follow Up Due
- Informal Meeting Queue
- Application Queue
- Close Queue
- Tomorrow Queue

### Purpose
Reduce decision fatigue and protect ETM-AAO.

The system works 24h across time zones.
The human does not need to stay awake 24h.
