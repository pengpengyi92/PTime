## Observation
A time block reserved for important execution was disrupted by low-intention drift after returning home. Delayed initiation reduced the block's useful progress. This is a qualitative self-observation, not a measured duration or quantified loss.

## Root decision
The optimization target is not merely the work produced during T, but the *quality of transition into T+1*:

```text
T (intent + action + context + energy)
  -> detect intentional / unintentional drift
  -> make a conscious adjustment
  -> micro-Close or deliberate Recovery
T+1 (greater readiness / stronger evidence / better options / restored energy)
```

**Rule:** Every T should create the conditions for a better T+1. Recovery counts when it sustainably improves the next state.

## Operational checklist for the next block
- Declare **one purpose**: Output / Connection / Observation / Recovery.
- Select **one first action** that can start in ten minutes.
- On drift: **STOP → RESET → CHOOSE → START / REST → CLOSE**.
- If repeated task-start failure is due to the home environment, move to a suitable predefined workplace when sensible.
- If fatigue and late hour dominate, switch to sleep / planned recovery instead of forcing output.
- Before leaving T: write one actual Close / evidence line and one T+1 first action.
