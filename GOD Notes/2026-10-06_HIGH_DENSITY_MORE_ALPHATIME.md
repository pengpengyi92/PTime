## 3. PACT / PBCT / PCCT self-consistency

Before high-value conversations, improve:
- PACT: people / relationship / institutional understanding
- PBCT: technical / research / systems evidence
- PCCT: communication / writing / public explanation

But do NOT wait for perfection.

Correct loop:
build
-> talk
-> receive feedback
-> build better
-> talk better.

## 4. P University makes PhD applications more fluent

P University creates an institutional mirror.

Instead of only asking:
"Will the professor accept me?"

Ask:
"What can I add to the lab / institute?"

Applicant contribution can be evaluated like a faculty / researcher KPI:
- research quality
- artifacts
- external impact
- momentum
- collaboration
- reputation lift
- cross-domain advantage
- career / placement optionality

This reframes PhD application as two-sided research matching.
