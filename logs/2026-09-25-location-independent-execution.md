# 2026-09-25 — Location-Independent Execution

Captured a new operating principle from today's discussion:

- Home can function as a remote execution base.
- Informal meetings, DD, CV/material sending, interview preparation, communication, research, and engineering do not inherently depend on an office.
- Travel can coexist with execution.
- PTime can route communication according to the current travel location and target-region working windows.
- PGlobal can keep global conversations active from any suitable location.
- Examples discussed: Zhongshan -> Shenzhen/HK, Reading -> London, and travel in Thailand/other countries while retaining remote execution capability.

**Closed principle:** Execution Base != Physical Base.
