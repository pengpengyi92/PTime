## Time architecture

### Mode A — Futian / East Rail
Normal workday default.
Passenger port opens 06:30.
Low cost, predictable, rail-heavy.

### Mode B — Huanggang / Hong Kong Island coach
24h resilience mode.
Direct island access via Sheung Wan / Wan Chai / Exhibition Centre.
Daytime roughly 20-minute headway; 16:00-02:00 roughly 15-minute headway according to current official Shenzhen port information.
Comfort advantage: seated journey and usable rest time.

### Mode C — High-speed rail
Speed mode.
Fast rail segment but with station process and final Hong Kong transfer.

## Time benchmark

Observed return:
~05:00 Wan Chai boarding
-> ~06:16 Futian home-area arrival.

Working planning envelope:
**~1.5 hours class from Futian home base to Central via Huanggang / Wan Chai under favorable conditions.**

Do not use as a guaranteed arrival time.

## AlphaTime rule

Choose route by objective:

- save money -> Futian / East Rail
- maximize seated comfort / resilience -> Huanggang coach
- maximize rail speed -> high-speed rail
- maximize interview performance -> stay in Hong Kong the previous night when justified

The optimization variable is:
**usable time + cognition + arrival reliability.**
