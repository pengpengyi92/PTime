  prevent duplicate New Year/Christmas IDs. UK bank holidays are England/Wales.
- Fixed/nth-weekday/explicit-year rules. Lunar and UK variable dates: 2026-2027.
  Unsupported dated years warn UNKNOWN. Source register links primary calendars.
- Cultural date and jurisdiction-tagged official period are separate; no automatic
  workday override or assertion about personal availability.
- Fifty-four bilingual general/professional/reconnect templates. No hard asks,
  inferred identity, real contacts, network access or transport.
- Explicit local preferences/history; canonical cycle across channels; recent
  contact, active conversation, template reuse, terminal action suppression.
- Explicit replies or user requests unlock follow-up timing, not immediate asks;
  cooldown, V2 restrictions, user rest, due/urgency and PCV opaque references.
- Four new CLI commands, leaving four legacy commands and V2 schemas intact.
