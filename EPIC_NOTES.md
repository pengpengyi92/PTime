# EPIC Notes

## 2026-09-25 — Travel x Global Execution

**Execution Base != Physical Base.**

Travel and professional execution do not need to be mutually exclusive. A person can be in Zhongshan, Reading, London, Thailand, or another location and still continue informal meetings, due diligence, CV/material sending, follow-ups, interview preparation, research, and engineering.

This creates a new operating mode:

```
Travel / Relaxing
      +
PTime routing
      +
PGlobal communication
      +
Remote Research & Engineering
      =
Location-Independent Execution
```

The strategic effect is that PMF is no longer constrained by the assumption that serious execution requires staying in Shenzhen or another fixed base.

**Principle:** Travel changes where we execute, not whether we execute.
