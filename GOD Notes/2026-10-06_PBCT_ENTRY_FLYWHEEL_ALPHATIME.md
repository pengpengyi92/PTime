# PTime / AlphaTime Note — PBCT Entry Flywheel

**Date:** 2026-10-06

AlphaTime for a technical-career target should compound across four block types:

```text
BUILD → CONNECT → CONVERT → RECOVER
```

- **BUILD:** coding / research / systems / artifacts.
- **CONNECT:** technical conversations / public discussions / practitioner contact.
- **CONVERT:** official applications / emails / interviews / follow-ups.
- **RECOVER:** food / coffee / walking / transit used to restore T+1 quality.

The key rule:

> Do not spend the whole day “preparing to apply” or the whole day “networking.”

A strong day can contain:
- a serious PBCT build block;
- one targeted high-signal interaction;
- one official recruiting action;
- enough recovery to preserve the next block.

Transit can remain AlphaTime when it carries:
- observation;
- note capture;
- route learning;
- recovery;
- lightweight communication.

Avoid purposeless drift.
