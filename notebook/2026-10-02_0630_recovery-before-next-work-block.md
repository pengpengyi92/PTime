# Recovery Before the Next Work Block

After an overnight field session, do not force the next morning observation window if execution quality is degraded.

Prefer:
- recovery first;
- reopen the next high-value daytime block with usable cognition;
- use lunch, afternoon, or after-work windows when the morning window is no longer optimal;
- preserve future weekday mornings for clean observation when needed.

Principle:
**Recovery protects the next usable AlphaTime block.**
